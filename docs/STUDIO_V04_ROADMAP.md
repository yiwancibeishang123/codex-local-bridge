# Codex Bridge Studio v0.4 — 产品架构与落地计划

## 产品定位
本地优先的 ChatGPT ↔ Codex 协作控制台。数据、项目授权和长记忆驻留 Ubuntu 的 SQLite；通过原有 OAuth/Tailscale Funnel 连接 ChatGPT 网页端，保留 VS Code Codex 插件。无第三方月费、无付费 API Key 的设计前提不变。

## 设计原则
1. 最少步骤：日常添加只读项目输入名称和目录，权限升级由本机用户明确确认。
2. 管理平面与执行平面隔离：MCP 服务 127.0.0.1:8767 通过 OAuth+Tailscale HTTPS 对外；Studio UI 独立 127.0.0.1:8768，仅本机登录可用，不能将其直接暴露给 Funnel。
3. 读取和写入不是一个权限。只读永不隐式升级；自动写回仅允许受审核的普通文件+固定隔离测试且 SHA/基线一致。
4. 可恢复：项目变更原配置备份、审计、必要时恢复；共享记忆记 revision、来源、项目边界及归档状态。
5. 诚实状态：Codex 任务 succeeded、测试通过、源码真正写回、源码提交、服务在线、OAuth 刷新是不同的事实，不合并显示成“全部正常”。
6. 限制上下文膨胀：长期记忆按项目检索并按相关性选择，绝不把全部任务日志无条件塞给模型。

## UX 导航
- 总览：本地 Bridge 状态、项目数、最近任务、共享记忆计数、快速操作。
- 项目：卡片搜索、当前权限、添加只读项目、授权终端操作提示、撤销授权。
- 共享记忆：按项目、类型、标签搜索与增改归档；显示 revision/来源时间。
- 任务：任务状态、运行/测试/落盘分离展示与链接审查。
- 连接：MCP localhost、Codex 可用性证据、Tailscale、授权情况以及错误。
- 设置：本地地址、安全约束、备份、版本与健康检查。

## 数据模型（本地 SQLite）
`studio.sqlite3`: notes(id, project_id, title, body, kind, tags, origin, source, provenance, created_at, updated_at, revision, archived)。
仍保留 `bridge.sqlite3` 中原任务/授权/OAuth 数据，不迁移、不导出凭证。记忆操作采用 SQL 参数化查询、乐观锁、容量上限和单项目隔离。默认不自动保存所有聊天；需要显式输入/确认，以降低冗余和敏感信息泄露。

## 交接协议（拟）
项目可维护：Project Brief、Decision Log、Work Handoff、Failure Ledger、Next Actions。通过 MCP 的 project-scoped 记忆查询/写入接口供 ChatGPT 和 Codex 显式调用；Codex 任务的上下文可在安全门禁、Token 预算和来源可追溯约束下按需注入相关记忆。项目更名/ID 重用须处理身份绑定，不能把新项目误认成旧项目。

## 发布里程碑
**v0.4-alpha（本轮实现目标）**
- 本地 UI 运行骨架+连接/项目/任务状态，安全登录、CSRF、仅 loopback。
- 项目只读注册入口（基于已经验收的本地脚本），有权限查看及撤销、危险授权仍需本机确认。
- 项目级 SQLite 记忆 CRUD、搜索、归档、修订冲突及测试。
- 实测 UI HTTP 请求和维护测试，不触碰生产服务。

**v0.4-beta（候选）**
- 新的 OAuth MCP 记忆工具，经实际网页发现及读写端到端验收。
- 远端项目注册仅申请、待本机审核，不能远端直接访问任意路径。
- 明确记忆交接模板、来源标记、去重、冲突提醒；可人工确认摘要。
- 前端任务详情/差异审阅、持久 UI 服务、诊断自检、导入导出。

**v0.4-stable（发布门禁）**
- 全套 pytest、HTTP/Auth/CSRF/路径安全测试、现场 Codex 双轮执行和 SHA/备份回滚。
- 部署脚本检测实际安装路径，备份与自动回滚，验证 systemd 与隧道/OAuth。
- 重启持久性/变更后重连/会话限额及错误提示验收；如不满足则不打稳定版。

## 后续 P1 / P2
- 连接健康趋势、错误根因和主动告警（限流、防噪声）。
- 文件目录树、文本 diff 浏览/审核（受白名单和大小限制）。
- Git 状态与分支关联（只读起步；危险仓库动作本机确认）。
- 可解释的记忆检索排序、去重、过期提醒和项目交接报告。
- 多项目并行任务、依赖关系与定期备份、导出及恢复验证。
- 本地无互联网可用时仍能浏览记忆、项目和任务历史。
- 一键更新、回滚与版本兼容性检测。

## 已知限制
1. ChatGPT 自身聊天上下文并不是可由 Bridge 直接读取的“隐藏无限记忆”；共享记忆必须通过显式 MCP 调用或任务交接保存。
2. 每个项目受 include 白名单约束；Studio 不提供任意文件系统访问或绕过确认授权的功能。
3. 当前固定测试沙箱为 Python unittest，无 GPU、ROS2、网络和第三方运行库自动挂载。
4. UI 不能向公网开放，也不应把本地 UI 的管理员令牌上传给任何 LLM。
5. 安全与权限更改需要本地人审；“普通开发无需逐次批准”和“无边界自动执行”不是同一要求。
